## How to Compile and Run

```bash
gcc VSCode_Questions/matrix_01_row_and_column_sums.c -o sums
./sums
```

The LeetCode and HackerRank function-style files contain only the function the site asks for (the judge supplies `main`), so they are meant to be pasted into the online editor rather than compiled on their own. Any `#include` lines at the top are harmless if the site already provides them.

## Notes

- `matrix_03_saddle_point.c` prints 0-based row and column indices. A saddle point is the minimum of its row and the maximum of its column.
- `strings_01_count_characters.c` counts every space character in the line. For the sample `C is fun 2026!` this gives `2 4 4 3` (the line has three spaces).
- Integer inputs in Part B use `long long` where overflow is possible.
